# 毕业设计管理系统 - 后端核心架构与接口开发文档

## 一、项目概述

### 1.1 项目名称
毕业设计管理系统 (Diploma Project Management System)

### 1.2 技术栈
- **框架**: Spring Boot 3.2.5
- **Java版本**: JDK 17
- **ORM框架**: MyBatis-Plus 3.5.6
- **数据库**: MySQL 8.2
- **安全框架**: Spring Security + JWT
- **API文档**: Knife4j 4.4.0 (Swagger增强版)
- **构建工具**: Maven

### 1.3 开发分工
本部分负责后端核心架构设计与API接口开发，包括：
- Controller控制器层（15个）
- Service业务逻辑层（7个服务）
- Entity实体类（19个）
- Mapper数据访问层（19个）
- DTO数据传输对象（14个）

## 六、Service服务层详解

### 6.1 GradAuthService - 认证服务

```java
public interface GradAuthService {
    GradLoginResponse login(GradLoginRequest request);   // 登录
    User getCurrentUser();                                 // 获取当前用户
    void activate(Integer userId, String phone, String password);  // 激活账号
    GradLoginResponse switchRole(Integer roleId);         // 切换角色
}
```

**核心逻辑:**
1. 根据用户名查询用户
2. BCrypt密码验证
3. 生成JWT Token
4. 返回用户信息和可用角色列表

### 6.2 SelectionService - 选题服务

```java
public interface SelectionService {
    StudentSelection submitSelection(SelectionSubmitDTO dto);  // 提交选题
    IPage<StudentSelection> listSelections(Integer page, Integer size, ...);  // 列表查询
    StudentSelection getCurrentSelection(Integer studentId, Integer batchId);  // 当前选题
    void reviewSelection(Integer selectionId, SelectionReviewDTO dto);  // 审核
}
```

**版本控制机制:**
- 每次提交自动递增 `version` 字段
- 支持多次修改，保留历史版本
- 只有最新版本可被审核

### 6.3 ScoreComputationService - 成绩计算服务

```java
public interface ScoreComputationService {
    void computeScore(Integer studentId, Integer batchId);  // 计算成绩
    void publishScore(Integer selectionId);                 // 发布成绩
}
```

**动态权重计算公式:**
```
totalScore = taskbookScore × taskbookWeight 
           + midtermScore × midtermWeight  
           + defenseScore × defenseWeight 
           + finalCheckScore × finalWeight

gradeLevel = 根据总分转换为五级制(A/B/C/D/F)
```

## 七、统一响应格式

### 7.1 Result<T> 通用响应体

```java
@Data
@AllArgsConstructor
@NoArgsConstructor
public class Result<T> {
    private int code;           // 状态码: 200成功, 其他失败
    private String message;    // 消息
    private T data;             // 数据
    
    public static <T> Result<T> success(T data) { ... }
    public static <T> Result<T> success() { ... }
    public static <T> Result<T> fail(String message) { ... }
}
```

### 7.2 错误码定义

| code | message | 场景 |
|------|---------|------|
| 200 | success | 成功 |
| 401 | 未认证，请先登录 | Token无效或缺失 |
| 403 | 无权限访问 | 角色权限不足 |
| 500 | 系统繁忙，请稍后重试 | 服务器内部错误 |

## 八、开发规范与约定

### 8.1 RESTful API规范

- 使用名词复数: `/api/topics`, `/api/users`
- HTTP方法语义: GET(查询), POST(创建), PUT(更新), DELETE(删除)
- 分页参数: `?page=1&size=10`
- 路径参数: `/{id}`
- 查询参数: `?status=approved&keyword=xxx`

### 8.2 异常处理

```java
// 业务异常抛出
throw new RuntimeException("用户名或密码错误");

// 全局捕获返回友好提示
@ExceptionHandler(RuntimeException.class)
public Result<Void> handleRuntimeException(RuntimeException e) {
    return Result.fail(e.getMessage());
}
```

### 8.3 MyBatis-Plus使用规范

- 继承 `ServiceImpl<Mapper, Entity>` 获得基础CRUD
- 使用 `LambdaQueryWrapper` 构建条件查询
- 乐观锁使用 `@Version` 注解
- 自动填充创建时间、更新时间
