# 毕业设计管理系统 - 前端页面与交互实现文档

## 一、项目概述

### 1.1 项目名称
毕业设计管理系统 (Diploma Project Management System) - 前端部分

### 1.2 技术栈
- **框架**: Vue.js 3.x (Composition API)
- **UI组件库**: Element Plus 2.x
- **构建工具**: Vite 5.x
- **状态管理**: Pinia
- **路由管理**: Vue Router 4
- **HTTP客户端**: Axios
- **CSS预处理**: SCSS
- **包管理器**: npm/pnpm

### 1.3 开发分工
本部分负责前端页面开发与用户交互实现，包括：
- 登录页面设计与表单验证
- 路由配置与权限守卫
- Pinia状态管理（用户登录态）
- Axios请求封装与拦截器
- 页面布局与样式设计

#### 3.1.2 核心代码实现

**模板部分:**
```vue
<template>
  <el-row class="login-page">
    <el-col :span="12" class="bg" />
    <el-col :span="6" :offset="3" class="form">
      <el-form ref="formRef" :model="formModel" :rules="rules" size="large">
        <!-- 标题 -->
        <el-form-item><h1>毕业设计管理系统</h1></el-form-item>
        
        <!-- 用户名 -->
        <el-form-item prop="username">
          <el-input v-model="formModel.username" 
                     :prefix-icon="User" 
                     placeholder="请输入用户名"
                     @keyup.enter="handleLogin" />
        </el-form-item>
        
        <!-- 密码 -->
        <el-form-item prop="password">
          <el-input v-model="formModel.password" 
                     show-password
                     :prefix-icon="Lock" 
                     type="password"
                     placeholder="请输入密码"
                     @keyup.enter="handleLogin" />
        </el-form-item>
        
        <!-- 记住我 + 登录按钮 -->
        <el-checkbox v-model="rememberMe">记住我</el-checkbox>
        <el-button type="primary" 
                   :loading="loading" 
                   :disabled="isSubmitting"
                   @click="handleLogin">
          {{ loading ? '登录中...' : '登 录' }}
        </el-button>
      </el-form>
    </el-col>
  </el-row>
</template>
```

**脚本逻辑:**
```javascript
<script setup>
import { ref, reactive } from 'vue'
import { User, Lock } from '@element-plus/icons-vue'
import { ElMessage } from 'element-plus'
import { useUserStore } from '@/stores'

const userStore = useUserStore()
const formRef = ref(null)
const loading = ref(false)
const isSubmitting = ref(false)  // 防重复提交锁

// 表单数据
const formModel = reactive({ username: '', password: '' })

// 验证规则
const rules = {
  username: [
    { required: true, message: '请输入用户名', trigger: 'blur' },
    { min: 3, max: 20, message: '用户名长度为3-20个字符', trigger: 'blur' }
  ],
  password: [
    { required: true, message: '请输入密码', trigger: 'blur' },
    { min: 6, max: 30, message: '密码长度为6-30个字符', trigger: 'blur' }
  ]
}

// 登录处理
const handleLogin = async () => {
  if (isSubmitting.value) return  // 防抖
  
  try {
    await formRef.value.validate()  // 表单验证
    
    isSubmitting.value = true
    loading.value = true
    
    await userStore.login(formModel)  // 调用API
    
    ElMessage.success('登录成功，正在跳转...')
    window.location.href = 'https://www.baidu.com'  // 跳转目标页
  } catch (error) {
    ElMessage.error('账号或密码错误，请重试')  // 统一错误提示
  } finally {
    loading.value = false
    setTimeout(() => { isSubmitting.value = false }, 1000)  // 1秒后解锁
  }
}
</script>
```

### 3.2 路由配置 (`router/index.js`)

```javascript
import { createRouter, createWebHistory } from 'vue-router'

const routes = [
  {
    path: '/login',
    name: 'login',
    component: () => import('@/views/login/index.vue'),
    meta: { requiresAuth: false }
  },
  {
    path: '/',
    component: MainLayout,
    meta: { requiresAuth: true },
    children: [
      { path: '', redirect: '/home' },
      { path: 'home', name: 'home', component: HomeIndex },
      { path: 'graduation/project-manage', component: ProjectManage },
      { path: 'graduation/my-project', component: MyProject },
      { path: 'graduation/notice', component: Notice },
      { path: 'profile', component: Profile },
      // ... 更多路由
    ]
  },
  { path: '/:pathMatch(.*)*', name: 'not-found', component: NotFound }
]

const router = createRouter({
  history: createWebHistory(),
  routes
})

// 路由守卫
router.beforeEach((to, from, next) => {
  const token = localStorage.getItem('token')
  
  if (to.meta.requiresAuth && !token) {
    next('/login')
  } else if (to.path === '/login' && token) {
    next('/')
  } else {
    next()
  }
})

export default router
```

### 3.4 HTTP请求封装 (`utils/request.js`)

```javascript
import axios from 'axios'
import { useUserStore } from '@/stores'
import { ElMessage } from 'element-plus'

const request = axios.create({
  baseURL: '/api',
  timeout: 30000,
  headers: { 'Content-Type': 'application/json' }
})

// 请求拦截器
request.interceptors.request.use(config => {
  const userStore = useUserStore()
  if (userStore.token) {
    config.headers.Authorization = `Bearer ${userStore.token}`
  }
  return config
})

// 响应拦截器
request.interceptors.response.use(
  response => {
    const res = response.data
    if (res.code !== 200) {
      ElMessage.error(res.message || '请求失败')
      return Promise.reject(new Error(res.message))
    }
    return response
  },
  error => {
    if (error.response?.status === 401) {
      localStorage.removeItem('token')
      window.location.href = '/login'
    }
    ElMessage.error(error.message || '网络错误')
    return Promise.reject(error)
  }
)

export default request
```

## 六、交互流程说明

### 6.1 登录流程

```
用户打开页面 → 显示登录表单
      ↓
输入用户名密码 → 点击登录按钮
      ↓
表单验证 → 通过?
      ↓ 是 ↓ 否
调用API ← 显示验证错误
      ↓
返回Token? → 通过?
      ↓ 是 ↓ 否
存储Token到localStorage/Pinia
      ↓
显示成功提示 → 跳转目标页面
```

### 6.2 权限控制流程

```
访问受保护页面
      ↓
检查Token是否存在
      ↓ 存在 ↓ 不存在
检查Token有效性
      ↓ 有效 ↓ 无效
允许访问 → 重定向到登录页
```
