### 1.1 项目名称
毕业设计管理系统 (Diploma Project Management System) - 数据库设计部分

### 1.2 数据库信息
- **数据库类型**: MySQL 8.2
- **数据库名**: `diploma_project`
- **字符集**: utf8mb4
- **排序规则**: utf8mb4_0900_ai_ci

本部分负责数据库表结构设计、SQL脚本编写及测试数据初始化，包括：
- 19张核心业务表的设计
- 表间关系与外键约束

## 三、表结构详细说明

### 3.1 用户与权限模块 (3张表)

#### users - 用户统一表
```sql
CREATE TABLE `users` (
  `user_id` INT NOT NULL AUTO_INCREMENT COMMENT '用户ID',
  `username` VARCHAR(50) NOT NULL COMMENT '登录名',
  `real_name` VARCHAR(100) DEFAULT NULL COMMENT '真实姓名',
  `phone` VARCHAR(20) DEFAULT NULL COMMENT '手机号',
  `email` VARCHAR(100) DEFAULT NULL COMMENT '邮箱',
  `password_hash` VARCHAR(255) NOT NULL COMMENT '密码哈希(BCrypt)',
  `role` VARCHAR(30) NOT NULL DEFAULT 'student' COMMENT '当前角色',
  `current_role_id` INT DEFAULT NULL COMMENT '当前角色ID',
  `college_id` INT DEFAULT NULL COMMENT '所属学院ID',
  `major_id` INT DEFAULT NULL COMMENT '所属专业ID',
  `is_activated` TINYINT(1) NOT NULL DEFAULT 0 COMMENT '是否已激活',
  `status` TINYINT NOT NULL DEFAULT 1 COMMENT '状态:0禁用 1正常',
  `signature_path` VARCHAR(255) DEFAULT NULL COMMENT '签名图片路径',
  `title` VARCHAR(50) DEFAULT NULL COMMENT '职称',
  `last_login` DATETIME DEFAULT NULL COMMENT '最后登录时间',
  `login_ip` VARCHAR(45) DEFAULT NULL COMMENT '登录IP',
  `failed_login_count` INT NOT NULL DEFAULT 0 COMMENT '连续失败次数',
  `locked_until` DATETIME DEFAULT NULL COMMENT '锁定截止时间',
  `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (`user_id`),
  UNIQUE KEY `uk_username` (`username`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户统一表';
```

#### roles - 角色表
```sql
CREATE TABLE `roles` (
  `role_id` INT NOT NULL AUTO_INCREMENT,
  `role_code` VARCHAR(30) NOT NULL COMMENT '角色编码: ADMIN/DEPT_ADMIN/MAJOR_DIRECTOR/TEACHER/STUDENT',
  `role_name` VARCHAR(50) NOT NULL COMMENT '角色名称',
  `description` VARCHAR(200) DEFAULT NULL COMMENT '描述',
  PRIMARY KEY (`role_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='角色定义表';
```

**角色编码说明:**
| role_code | role_name | 说明 |
|-----------|-----------|------|
| ADMIN | 校级管理员 | 最高权限，管理所有学院 |
| DEPT_ADMIN | 院系管理员 | 管理本院系所有专业 |
| MAJOR_DIRECTOR | 专业负责人 | 管理本专业的毕设流程 |
| TEACHER | 指导教师 | 指导学生、审核任务书/报告 |
| STUDENT | 学生 | 完成选题、提交各阶段材料 |

### 3.4 成绩管理模块 (1张表)

#### final_scores - 成绩总表
```sql
CREATE TABLE `final_scores` (
  `score_id` INT NOT NULL AUTO_INCREMENT,
  `selection_id` INT NOT NULL COMMENT '选题ID',
  `batch_id` INT NOT NULL COMMENT '批次ID',
  `student_id` INT NOT NULL COMMENT '学生ID',
  `taskbook_score` DECIMAL(5,2) DEFAULT NULL COMMENT '任务书成绩',
  `midterm_score` DECIMAL(5,2) DEFAULT NULL COMMENT '中期成绩',
  `defense_score` DECIMAL(5,2) DEFAULT NULL COMMENT '答辩成绩',
  `final_check_score` DECIMAL(5,2) DEFAULT NULL COMMENT '终期成绩',
  `total_score` DECIMAL(5,2) DEFAULT NULL COMMENT '加权总分',
  `grade_level` VARCHAR(2) DEFAULT NULL COMMENT '五级制:A/B/C/D/F',
  `is_published` TINYINT(1) DEFAULT 0 COMMENT '是否已发布',
  `published_by` INT DEFAULT NULL COMMENT '发布人',
  `published_at` DATETIME DEFAULT NULL COMMENT '发布时间',
  `calculated_at` DATETIME DEFAULT NULL COMMENT '计算时间',
  `created_at` DATETIME DEFAULT CURRENT_TIMESTAMP,
  `updated_at` DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (`score_id`),
  UNIQUE KEY `uk_selection` (`selection_id`),
  KEY `idx_student_batch` (`student_id`, `batch_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='成绩总表';
```

**成绩计算公式:**
```sql
total_score = taskbook_score * taskbook_weight
           + midterm_score * midterm_weight
           + defense_score * defense_weight
           + final_check_score * final_weight
```

## 五、索引优化策略

### 5.1 已创建索引清单

| 表名 | 索引名 | 字段 | 类型 | 用途 |
|------|--------|------|------|------|
| users | uk_username | username | UNIQUE | 登录名唯一 |
| student_selections | uk_batch_student_version | batch_id, student_id, version | UNIQUE | 防止重复选题 |
| files | idx_relation | relation_type, relation_id | INDEX | 按关联对象查询 |
| sign_ins | uk_student_date | student_id, sign_in_date | UNIQUE | 每日只能签到一次 |
| notifications | idx_receiver_read | receiver_id, is_read | INDEX | 未读消息查询 |
| operation_logs | idx_user | user_id | INDEX | 按用户查日志 |
| operation_logs | idx_created_at | created_at | INDEX | 按时间查日志 |
| system_configs | uk_config_key | config_key | UNIQUE | 配置键唯一 |

### 5.2 建议添加的索引

```sql
-- 批次按状态查询
ALTER TABLE project_batches ADD INDEX idx_status (status);

-- 选题按学生查询
ALTER TABLE student_selections ADD INDEX idx_student (student_id);

-- 选题按题目查询
ALTER TABLE student_selections ADD INDEX idx_topic (topic_id);

-- 成绩按学生+批次查询
ALTER TABLE final_scores ADD INDEX idx_student_batch (student_id, batch_id);
```
